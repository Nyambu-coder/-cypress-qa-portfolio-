# Cypress QA Automation Portfolio

A collection of automated end-to-end tests built with **Cypress**, demonstrating core QA automation skills: functional testing, navigation flows, form validation, and negative testing.

## What's tested

- **Saucedemo** (`login.cy.js`) — login flow with valid credentials
- **Automation Exercise** (`homepage.cy.js`) — homepage load verification and navigation to the Products page

## Tech stack

- Cypress (JavaScript/TypeScript E2E testing framework)
- Node.js / npm


## How to run these tests

1. Clone this repo
2. Run `npm install`
3. Run `npx cypress open`
4. Select a spec file to run it
